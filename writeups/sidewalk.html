Art commissions

My inistial work started off with attempting a 'paint by number' system. The idea was that each section of a mathematically defined object could get its own number which could then be referenced.

This style ended up not looking that good. And with a job popping up to paint some sidewalks for a local event I thought I'd make it better. I knew from this previous project that I could get a recurring pattern by using a function that utilized sine and cosine. sin(y) would allow for a repeating pattern in the y direction and cos(f(x)) helps extend the function farther than 2π. sin and cosine can be interchanged, they just change the phase and will alter the output slightly.

Next the intersections need to get defined so that each section can get its own color. Each intersection's y-value is a multiple of π which makes it easy, but the x values change over x. This is realated to everytime f(x) reaches the next multiple of π. I had some previous experience with this and adding sin(f(x)) to f(x) gives a steping function that can be reduced down to give unique values. Notice how each black line ends at an intersection.

With this, and the patchwork pattern already formed by the previous function. an Id for each position can be aquired.

This only gives half of what I want, I need to take the same function and reflect it across the x axis to get the other half.

Good enough as a template. Different colors were tested and this one was chosen. Next up was the build out stencils and make the art.
